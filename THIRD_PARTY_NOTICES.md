# Third-party licenses and notices

Audit snapshot for Template App `1.0.0+7`, checked 2026-10-24. This is a reusable inventory, not a substitute for checking the exact artifacts and terms in each derived app.

## Commercial-use rule

Only add or update a dependency, plugin, icon set, font, image, or other bundled asset after checking the exact resolved release and its license. The license must permit commercial use. Do not use material with non-commercial, unclear, or missing terms. Preserve license texts, copyright notices, attribution, and any other conditions; update this inventory and the app's About/open-source licenses screen when the dependency set changes. Review both the pub lockfile and Android/Gradle dependency versions before release. Recheck this inventory whenever Flutter or a dependency is upgraded.

## Current app dependencies

The app's only third-party pub runtime package is `url_launcher` 6.3.3 (BSD-3-Clause), used to open the configured privacy-policy URL in the external browser. Its exact locked platform implementation and interface packages are `url_launcher_android` 6.3.33, `url_launcher_ios` 6.4.2, `url_launcher_linux` 3.2.3, `url_launcher_macos` 3.2.6, `url_launcher_platform_interface` 2.3.2, `url_launcher_web` 2.4.3, and `url_launcher_windows` 3.1.6; each is BSD-3-Clause. Its locked `plugin_platform_interface` 2.1.8 and `web` 1.1.2 dependencies are also BSD-3-Clause. The direct package license is retained at `licenses/url_launcher_LICENSE.txt`. The runtime also uses the Flutter SDK, whose framework is BSD-3-Clause; Flutter documents that engine components have their own licenses and notices. Use Flutter's license registry/page so SDK and package notices are available in the distributed app.

The other direct pub dependencies are `flutter` (SDK runtime), `flutter_test` (SDK test-only), and `flutter_lints` 6.0.0 (development-only, BSD-3-Clause). Locked hosted test/lint dependencies are also not app runtime dependencies. Their reviewed license files/metadata group as follows; exact resolved versions are recorded in `pubspec.lock`:

- BSD-3-Clause: `async`, `boolean_selector`, `characters`, `collection`, `flutter_lints`, `leak_tracker`, `leak_tracker_flutter_testing`, `leak_tracker_testing`, `lints`, `matcher`, `meta`, `path`, `source_span`, `stack_trace`, `stream_channel`, `string_scanner`, `term_glyph`, `test_api`, `vector_math`, and `vm_service`.
- Apache-2.0: `clock`, `fake_async`, and `material_color_utilities`.
- Flutter SDK components: `flutter`, `flutter_test`, and `sky_engine`; follow the SDK's framework and engine notices described above.

The Android build declares Android Gradle Plugin 9.1.0 and Kotlin Android plugin 2.4.0, plus Flutter's SDK Gradle plugins. These are build tools, not app runtime libraries. The upstream Kotlin license is Apache-2.0, and Android tooling ships component-level license notices; recheck those exact plugin releases and their notices when changing the versions.
